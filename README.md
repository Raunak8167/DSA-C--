# DSA in C++

A hands-on C++ learning repository covering programming fundamentals, problem-solving exercises, data structures concepts, and algorithm practice.

This repository records the learning process through small programs, lecture examples, and topic-wise practice. The code is intentionally kept as a learning archive: original solutions are preserved rather than rewritten just for presentation.

## Compile and run

Install a C++ compiler such as GCC (g++).

Compile a source file:

```bash
g++ -std=c++17 path/to/program.cpp -o program
```

Run on Linux/macOS:

```bash
./program
```

Run on Windows PowerShell:

```powershell
g++ -std=c++17 path/to/program.cpp -o program.exe
./program.exe
```

Use the compiler standard required by the particular exercise if it differs from C++17.

## Repository conventions

- C++ source files are the primary content.
- Compiled executables and build output are generated locally and are not committed.
- Original practice filenames and solutions are retained where their intent is not yet clear.
- New exercises should be added to the closest topic folder and use descriptive filenames where practical.

## About

A personal C++ and data-structures-and-algorithms learning archive maintained alongside undergraduate computer science studies. It combines a clear topic-based layout with an honest record of practice and progress.
